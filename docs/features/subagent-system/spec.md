# 子 Agent 系统 Spec

## 背景

YCode 当前只有主 Agent 执行循环。代码探索、方案制定和其他可委派任务都会直接占用主对话历史；耗时任务还会阻塞主 Agent，无法与其他工作并行。系统也缺少对子 Agent 的角色、模型、工具权限、运行轮次、生命周期和结果回传进行统一约束的机制。

本功能将子 Agent 建设为完整的项目级扩展能力，而不是几个写死的辅助流程。项目可以用 Markdown 角色文件定义专用 Agent，主 Agent 通过统一工具选择角色或 Fork 当前对话，并选择同步或异步执行。

## 目标

- 提供统一的子 Agent 工具入口，接收任务、可选角色和同步/异步模式。
- 支持项目在 `.ycode/agents/<name>.md` 中自定义角色。
- 自定义角色使用 YAML Frontmatter 声明角色名称、用途说明、独立模型、工具白名单、工具黑名单、最大执行轮次和权限模式。
- 使用 Markdown 正文定义角色指令；角色从空白对话开始执行，不继承主对话。
- 严格校验角色文件；单个角色损坏、重名或引用不存在的模型/工具时，仅使该角色不可用，不影响其他角色和主 Agent。
- 提供内置只读角色 `explore` 和 `plan`；项目角色不能覆盖内置角色。
- 角色模型省略时使用当前 Anthropic 模型，指定时引用已有 Anthropic Provider。
- 支持无角色 Fork：继承产生当前工具调用的父请求历史、模型和工具定义，追加专用工作指令与任务。
- 保持 Fork 请求前缀与父请求一致，使满足 Provider 缓存条件时能够读取 Prompt Cache。
- 支持创建时固定为同步或异步；不提供运行中转换。
- 同步任务由父 Agent 等待最终结果；异步任务立即返回任务 ID，并由任务管理器继续执行。
- 隔离每个子 Agent 的消息历史、审批状态、文件读取状态、上下文管理和 Token 统计。
- 共享模型客户端、Hook 引擎、项目文件系统和工具执行基础设施。
- 在工具执行前叠加全局防嵌套规则、角色限制、异步任务限制和权限规则。
- 子 Agent 遇到需要用户确认的操作时自动拒绝，并将拒绝结果交还模型继续处理。
- 让异步任务可列出、查看详情和终止；记录状态、结果、Token 用量与起止时间。
- 将完成通知注入主 Agent 的下一个安全请求边界，不取消流式请求，也不擅自启动新回合。
- 保持 Hook 在子 Agent 中生效，并隔离父子 Reminder。
- ESC 或 Ctrl+C 取消当前父回合，并级联取消该回合创建的全部同步与异步子 Agent。

## 功能需求

### 统一入口与创建模式

- **F1：统一工具入口。** 系统提供一个稳定的子 Agent 工具，参数包括非空 `task`、可选 `role` 和可选 `mode`。`mode` 仅接受 `sync` 或 `async`。
- **F2：定义式创建。** 指定 `role` 时，从空白消息历史启动固定角色；省略 `mode` 时默认同步，也可显式指定异步。
- **F3：Fork 创建。** 省略 `role` 时进入 Fork 模式并强制异步；省略 `mode` 等价于 `async`，显式指定 `sync` 返回参数错误。
- **F4：模式不可变。** 同步或异步在任务创建时确定，运行中不能自动或手动转换；不提供超时转后台和快捷键转后台。
- **F5：稳定工具契约。** 项目角色名称不写入工具参数的动态枚举，角色增删不会改变工具 Schema；角色名称在执行时校验。

### 项目自定义角色

- **F6：角色发现范围。** 系统提供内置角色，并在启动时扫描当前项目根目录下的 `.ycode/agents/*.md`；不扫描用户目录、父目录或嵌套目录。
- **F7：角色文件身份。** 每个角色文件必须使用 Markdown 和 YAML Frontmatter，文件名必须与 Frontmatter 中的规范化 `name` 一致。
- **F8：必填内容。** `name`、`description` 和 Markdown 正文必须存在且非空。
- **F9：可选配置。** `model` 引用已有 Anthropic Provider，省略时使用当前活动 Provider；`allowed-tools` 是工具白名单，省略时继承定义式子 Agent 的基础工具集；`denied-tools` 从已继承或已允许的工具中继续排除；`max-rounds` 是正整数且默认 `10`；`permission` 可取 `strict`、`default` 或 `allow`，默认 `default`。
- **F10：严格校验。** 未知字段、格式错误、未知模型、未知工具、白黑名单重叠、名称与文件名不一致均使该角色不可用。一个角色失败不得阻止其他角色或主 Agent 启动。
- **F11：名称冲突。** 项目角色不得覆盖 `explore`、`plan` 等内置角色；规范化后重名的项目角色均不可用，不根据扫描顺序选择胜者。
- **F12：角色指令。** 定义式子 Agent 使用 YCode 的基础行为与工具规则，并叠加角色 Markdown 正文；不继承父对话消息、父任务 Reminder 或父权限授权记录。
- **F13：内置角色。** `explore` 用于探索项目结构、代码和相关证据，只能使用读取与搜索类工具；`plan` 用于根据任务和项目现状制定计划，只能使用读取与搜索类工具；不提供 `verify` 或通用 `general` 角色。

### Fork 继承与缓存兼容

- **F14：历史快照。** Fork 继承“产生本次工具调用的父模型请求”的完整输入历史，不加入父模型当前尚未完成的 assistant 工具调用消息。
- **F15：请求前缀继承。** Fork 首次请求复用父请求的模型、工具定义及顺序、稳定系统指令、动态补充和历史消息；新增内容只追加在继承前缀之后。
- **F16：任务注入。** Fork 的首条新增用户消息包含强制工作规范、具体任务和结果格式要求；子 Agent 不等待或请求额外用户输入。
- **F17：Fork 工作规范。** 注入指令要求子 Agent 不再创建子 Agent、不主动与用户对话、不请求用户确认、直接使用工具完成工作，并返回约 1000 个汉字以内且使用“结论、证据、风险/待办”三个小节的结果正文。
- **F18：缓存可观测性。** 系统保持 Fork 继承前缀逐字和顺序一致；当 Provider 的长度、有效期等缓存条件满足时，首次请求应产生缓存读取用量。缓存条件不满足不视为子 Agent 执行失败。

### 执行循环与结果

- **F19：跑到底执行。** 子 Agent 创建后立即执行参数中的任务，不进入交互输入循环。模型产生工具调用时执行工具并继续请求，直到得到正常的纯文本终止结果或进入终止状态。
- **F20：完成判定。** 正常返回文本且没有工具调用时标记 `completed`；同时返回文本和工具调用时继续执行；没有文本也没有工具调用时标记 `failed` 且错误码为 `empty_result`；达到最大轮次时标记 `limit_reached` 并保留最后一段可用文本；输出上限、内容过滤和 Provider 错误导致的异常停止标记 `failed`；用户或父回合取消时标记 `cancelled`。
- **F21：工具错误恢复。** 普通工具错误和权限拒绝作为工具结果返回子模型，由模型决定是否换用其他方案；不得直接把一次工具失败等同于整个任务失败。
- **F22：统一结果结构。** 同步工具结果、异步任务详情和完成通知使用相同的 `task_id`、`status`、`creation_mode`、`role`、`result`、`usage`、`started_at`、`finished_at` 和 `error` 字段。
- **F23：结果正文。** `result` 使用最后一条 assistant 消息中的文本。运行时负责外层结构，不要求模型生成严格 JSON，也不机械截断模型结果。
- **F24：Token 用量。** 每个子 Agent 独立累计输入、输出、缓存创建和缓存读取 Token；父 Agent 的统计不得包含子 Agent 用量。

### 隔离与共享

- **F25：运行状态隔离。** 每个子 Agent 独立维护消息历史、上下文压缩状态、权限会话、临时授权、文件读取状态、Reminder 和 Token 计数，不得修改父 Agent 对应状态。
- **F26：基础设施共享。** 父子 Agent 共享项目文件系统、模型客户端或客户端池、工具执行基础设施、Hook 引擎和已建立的外部连接；不得仅为 Fork 重复建立同配置连接。
- **F27：Fork 权限初值。** Fork 继承父 Agent 当前权限模式的值，但使用空白的独立权限记录，不继承 `allow once` 或会话临时授权。
- **F28：定义式权限初值。** 定义式子 Agent 使用角色声明与父 Agent 当前权限模式中更严格的模式，并使用空白的独立权限记录；角色权限只能收窄父权限，不能提权。父 Agent 处于 plan-only 时，所有子 Agent 额外受到只读硬限制。

### 工具与权限防线

- **F29：执行前强制检查。** 子 Agent 每次工具执行前依次应用全局防嵌套与防扩权规则、创建模式的基础工具边界、自定义角色白名单和黑名单、异步任务工具白名单、权限引擎与 Hook 权限结果。
- **F30：工具可见性与执行权分离。** 为保持 Fork 缓存兼容，Fork 对模型保留父请求的原始工具定义；工具可见不代表允许执行，所有限制以执行前检查为最终准则。
- **F31：禁止嵌套。** 子 Agent 创建工具在任何子 Agent 中均无条件拒绝，角色配置、Fork 继承或权限模式均不能重新允许。
- **F32：禁止运行时扩权。** 子 Agent 不得安装、激活或加载会改变其运行时能力边界的扩展；此类工具即使可见也在执行前拒绝。
- **F33：Fork 工具继承。** Fork 的基础执行集合来自父 Agent 当前有效工具集，包括父 Agent 已有的标准写文件和命令工具。
- **F34：定义式角色过滤。** 自定义角色的白名单先收窄基础集合，黑名单再排除；`explore` 和 `plan` 始终只读。
- **F35：异步任务限制。** 异步任务默认允许标准代码读取、搜索、写入、编辑和命令工具；外部或 MCP 工具必须同时属于继承集合并进入全局异步白名单。
- **F36：不可覆盖的拒绝。** 工作区边界、命令安全、全局防嵌套、角色黑名单、异步白名单和 Hook 明确拒绝不能被 `permission: allow` 覆盖。
- **F37：非交互审批。** 任一检查最终产生 `ASK` 时，子 Agent 自动按拒绝处理，并把拒绝原因作为工具结果返回模型；不得显示审批 UI、暂停等待用户或自动批准。

### 同步与异步任务

- **F38：同步执行。** 同步任务由父工具调用持续等待，完成后直接返回统一结果；无论运行多久都不会自动转为异步。
- **F39：异步执行。** 异步任务创建后立即向父 Agent 返回 `task_id` 和 `running` 状态，由任务管理器继续执行。
- **F40：统一管理。** 同步与异步子 Agent 均登记到同一任务管理器，使用同一状态模型和统计方式。
- **F41：并发限制。** 当前会话最多同时运行 4 个子 Agent，同步和异步合并计数；该上限允许全局配置为其他正整数。
- **F42：超限行为。** 达到并发上限时，新任务立即返回明确错误，不排队；终态任务立即释放并发名额。
- **F43：任务状态。** 任务至少支持 `running`、`completed`、`failed`、`cancelled` 和 `limit_reached`。
- **F44：任务记录。** 管理器维护任务参数、创建模式、角色、状态、结果、错误、Token 用量和起止时间。记录保留到当前会话结束、清空或恢复其他会话。

### 完成通知

- **F45：安全注入。** 异步任务进入终态后生成一次结构化通知，并在主 Agent 的下一个安全模型请求边界注入。
- **F46：不打断当前请求。** 通知不得取消、修改或重启正在进行的模型流；如果当前父回合还会产生下一次模型请求，则在该请求前注入，否则排队到下一次用户消息触发的请求。
- **F47：不主动对话。** 完成通知不得自行启动新的主 Agent 回合。UI 可以显示非阻塞完成提示。
- **F48：通知顺序。** 多个待注入通知按完成时间排序、批量注入，并保证每个任务最多注入一次。
- **F49：同步任务不通知。** 同步任务通过工具结果直接返回，不再产生异步完成通知。

### Hook

- **F50：子 Agent Hook。** 子 Agent 触发现有的回合、消息、工具、上下文压缩和 Agent 错误事件，不重复触发会话开始和结束事件。
- **F51：Hook 上下文。** 子 Agent Hook 上下文包含任务 ID、定义式或 Fork、角色以及同步或异步模式。
- **F52：共享规则状态。** 父子 Agent 共用 Hook 规则和会话级 `once` 状态；任何 Agent 首次命中后，该规则在本会话不再重复执行。
- **F53：Reminder 隔离。** Hook 产生的 Reminder 只能进入触发它的 Agent，不得被其他父子 Agent 消费。
- **F54：Hook 权限。** Hook 的 `DENY` 保持拒绝；Hook 的 `ASK` 在子 Agent 中自动拒绝。

### 用户控制与生命周期

- **F55：任务列表。** `/tasks` 列出当前会话全部任务，显示 ID、状态、创建模式、角色、运行时长和 Token 总量。
- **F56：任务详情。** `/tasks <task-id>` 显示任务参数、完整结果或错误、分类 Token 用量及起止时间。
- **F57：任务终止。** `/tasks stop <task-id>` 取消运行中的任务并标记 `cancelled`；不存在、已结束或无法唯一识别的 ID 不执行取消，并返回明确提示。
- **F58：父回合取消。** ESC 或 Ctrl+C 取消当前父 Agent 回合，并级联取消由该回合创建的全部同步和异步子 Agent。
- **F59：取消边界。** 此前已经正常结束的父回合所遗留的异步任务不受本次取消影响。
- **F60：会话边界。** 清空当前会话、恢复其他会话或退出程序时，取消当前会话仍在运行的全部子 Agent，并清除任务记录。
- **F61：进程内生命周期。** 任务和结果不跨进程持久化；程序重启后不恢复异步任务或历史任务记录。

## 非功能需求

- **N1：Provider 范围。** 本期只开发和验收 Anthropic；核心角色、任务和调度边界保持 Provider 无关。OpenAI 适配不进入本期。
- **N2：现有功能兼容。** 未调用子 Agent 时，主 Agent 对话、工具、权限、上下文、Skill、Hook、MCP、会话和命令的正常行为保持不变。
- **N3：基本状态隔离。** 在约定的最多 4 个并发任务范围内，父子 Agent 的消息、权限记录、Reminder、上下文和 Token 统计不得混用。
- **N4：执行安全。** 防嵌套、工作区、命令、角色和异步工具限制必须在工具执行前生效，不能只依赖 Prompt。
- **N5：缓存前缀确定性。** Fork 继承内容保持稳定顺序和确定性序列化，以满足 Anthropic Prompt Cache 的前缀匹配条件。
- **N6：交互可用。** 异步任务不阻塞主对话；同步任务运行时，ESC 和 Ctrl+C 仍能取消当前回合及其子任务。
- **N7：行为可观测。** 工具结果、任务通知和 `/tasks` 命令能够展示任务状态、结果、错误、时间和实际 Token 用量。
- **N8：基本错误隔离。** 单个无效角色或单个子 Agent 失败不应阻止主 Agent 和其他合法任务继续使用。
- **N9：基本生命周期收尾。** 清空、恢复和退出时取消当前会话任务并释放本功能直接创建的资源；不实现执行现场恢复。
- **N10：功能性验证。** 使用单元测试、集成测试和真实终端端到端测试覆盖核心行为；不调用真实付费 API。
- **N11：不做生产级验证。** 不进行压力测试、性能基准、长时间稳定性运行、大规模并发、复杂竞态或故障注入、多平台矩阵及真实外部服务验证。
- **N12：不扩展生产可靠性工程。** 不为本功能增加持久化任务队列、跨进程恢复、分布式调度、自动重试、熔断、监控指标或理论边界场景的额外抽象。
- **N13：代码风格。** 遵循现有项目结构；Python 标识符使用英文，新增注释使用简洁中文。

## 不做的事

- OpenAI Provider 的子 Agent、Fork、Prompt Cache 或协议适配。
- 用户级、父目录、子项目或嵌套目录的角色发现。
- 角色市场、远程安装、自动更新、版本管理或签名验证。
- 角色热重载、`/agents` 管理命令或运行中修改角色快照。
- `verify`、`general` 或其他额外内置角色。
- 子 Agent 创建子 Agent；不支持 A→B→C 形式的嵌套执行。
- Fork 时切换模型、替换工具 Schema 或选择固定角色。
- 从父 Agent 继承临时审批记录、Reminder、Token 统计或上下文事务。
- 子 Agent 向用户发起权限审批、暂停等待确认或自动批准 `ASK`。
- 同步任务自动超时转异步，或通过快捷键在同步与异步之间转换。
- 异步任务自动发起新的主 Agent 回合。
- 跨进程任务持久化、程序重启恢复或跨会话迁移任务。
- 后台任务排队、优先级、依赖图、自动重试、周期任务或分布式调度。
- 自动创建独立工作树、文件锁、写冲突检测、合并或回滚多个 Agent 的文件修改。
- 要求子模型输出严格 JSON；结构化外层由运行时生成。
- 角色结果的强制截断、自动摘要或二次模型整理。
- 对 Hook 系统增加新的事件类型或新的动作类型。
- 对 Skill 系统进行扩展；子 Agent 中只禁止会改变运行时能力的 Skill 操作。
- 压力测试、性能基准、长时间运行、大规模并发、复杂故障注入、多平台矩阵或真实付费 API 验证。
- 持久化队列、分布式锁、监控告警、熔断等生产级可靠性工程。

## 验收标准

- **AC1（F1–F5）调用契约。** 统一工具能够创建定义式同步、定义式异步和 Fork 异步任务；空任务、非法模式、不存在的角色及 Fork 同步调用返回明确错误，运行中不能改变模式。
- **AC2（F6–F13）角色系统。** 合法项目角色能够被发现并应用正文、模型、工具限制、轮次和权限配置；损坏、重名、冲突或引用无效资源的角色独立失效；内置 `explore`、`plan` 始终只读。
- **AC3（F14–F18）Fork 与缓存。** Fork 首次请求继承触发工具调用的父请求前缀，不包含未完成工具调用；追加规定的任务指令。在满足 Anthropic 缓存条件的受控场景中观察到缓存读取 Token。
- **AC4（F19–F24）执行与结果。** 子 Agent 无需用户输入即可持续执行工具直到完成；纯文本、空结果、轮次耗尽、异常停止和取消分别进入正确状态。结果使用统一结构并记录独立的分类 Token 用量。
- **AC5（F25–F28）隔离与共享。** 多个父子 Agent 同时运行时，消息、上下文、权限记录、读取状态、Reminder 和 Token 统计互不串扰；文件系统、Hook、模型访问和外部连接按约定共享。
- **AC6（F27–F37）工具与权限。** Fork 保持父工具定义并可使用父 Agent 的标准写工具；定义式角色不能把权限提升到父 Agent 当前模式以上，plan-only 父任务创建的子 Agent 始终只读；全局防嵌套、运行时防扩权、角色限制、异步白名单、工作区、命令安全和 Hook 拒绝均在执行前生效。所有 `ASK` 自动拒绝并反馈给子模型。
- **AC7（F38–F44）同步、异步与并发。** 同步任务一直由父调用等待；异步任务立即返回任务 ID 并继续运行。同步与异步任务由同一管理器记录，默认并发上限为 4，超限调用立即失败且不排队。
- **AC8（F45–F49）完成通知。** 异步任务通知不会修改正在进行的模型请求或主动开启新回合；通知在下一个安全请求边界按完成顺序注入且只注入一次。同步任务不产生异步通知。
- **AC9（F50–F54）Hook。** 子 Agent 触发除会话起止外的既有 Hook 事件并携带任务上下文；`once` 状态在父子间共享，Reminder 按 Agent 隔离，权限结果遵守子 Agent 非交互规则。
- **AC10（F55–F57）任务命令。** `/tasks`、`/tasks <id>` 和 `/tasks stop <id>` 分别完成列表、详情和终止操作，并正确处理空列表、无效 ID、终态任务和运行任务。
- **AC11（F58–F59）父回合取消。** ESC 或 Ctrl+C 取消当前父回合及该回合创建的全部同步、异步子 Agent，但不影响此前正常回合遗留的异步任务。
- **AC12（F60–F61）会话生命周期。** 清空、恢复其他会话和退出程序会取消当前会话任务并清除记录；程序重启后不恢复旧任务。
- **AC13（N1–N5）兼容与范围。** 不调用子 Agent 时现有核心流程和测试保持正常；新增 Provider 行为只覆盖 Anthropic；Fork 前缀具有确定性，核心任务模型不依赖 Anthropic SDK 类型。
- **AC14（N6–N12）验证边界。** 使用本地 Provider、Hook、工具和 MCP 替身验证功能，不调用真实付费 API，也不执行压力、性能、长期稳定性、大规模并发或复杂故障注入测试。
- **AC15（核心端到端）完整交互。** 在真实终端中完成定义式同步、定义式异步、Fork 异步、结果通知和任务命令的主流程。
- **AC16（取消端到端）取消与收尾。** 在真实终端中验证 ESC、Ctrl+C、任务停止、会话清空及退出时的任务取消边界。
