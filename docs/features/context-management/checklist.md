# YCode 上下文管理 Checklist

> 状态：已完成

> 所有项目必须通过实际运行或观察后才能勾选。验证使用虚拟 Provider、临时工作区和
> 占位秘密，不连接真实模型服务，不扩展生产级验证。

## 请求预算与处理顺序

- [x] 同时存在超限工具结果和超阈值历史时，先完成工具结果外置，再发起一次摘要请求；
  摘要请求不会递归触发上下文预检。（对应 AC1；验证：ContextManager/集成测试）
- [x] Token 估算覆盖 System Prompt、动态 supplements、工具 Schema、全部消息和结构
  开销；主请求实际 input usage 只向上校准估算，且没有 Token Count API 调用。
  （对应 AC2；验证：TokenEstimator 单元测试和请求捕获）
- [x] 顶层配置默认窗口为 200,000，自动阈值为 167,000，继续上限为 180,000；自定义
  合法窗口正确换算，布尔、字符串、浮点及不大于 33,000 的值被拒绝。
  （对应 AC9；验证：配置和 ContextPolicy 测试）

## 工具结果外置

- [x] 内建、MCP、成功、错误和权限拒绝结果使用相同计量规则；脱敏后最终序列化结果
  恰好 50 KiB 时保留，超过时生成稳定 JSON 引用。（对应 AC3；验证：外置单元测试）
- [x] 默认预览不超过 4 KiB，约包含 3 KiB 开头和 1 KiB 结尾；UTF-8 字符不会被错误
  截断。（对应 AC3；验证：ASCII、中文和多字节预览测试）
- [x] 单消息工具结果合计超过 200 KiB 时，先处理单结果超限，再按剩余结果大小降序
  外置；引用和预览计入最终大小，必要时退化为最小引用。（对应 AC4；验证：聚合测试）
- [x] 每个外置结果具有可读取 manifest 和不超过 50 KiB 的连续分片；按顺序重组后与
  脱敏后的完整序列化内容一致，总字节数和 SHA-256 匹配。（对应 AC5；验证：存储测试）
- [x] 同一个已经外置的工具结果经过后续请求预检时不会重复写盘或嵌套外置。
  （对应 AC5；验证：幂等测试）
- [x] 测试秘密不会出现在分片、manifest、引用、预览、终端状态或错误消息中，其他内容
  保持可读。（对应 AC6；验证：脱敏哨兵断言）
- [x] 模拟写盘失败时，当前回合以 `context_storage_error` 结束；模型不收到截断结果，
  本轮历史和临时摘要均不提交。（对应 AC7；验证：写盘失败和事务测试）
- [x] 正常关闭只删除当前会话目录；启动清理只删除超过 24 小时且进程已不存在的有效
  遗留目录，活动、较新或无法确认的目录保留；`.ycode/context/` 被 Git 忽略。
  （对应 AC8；验证：基础生命周期测试和 Git 忽略检查）

## 摘要请求与结构

- [x] 超过自动阈值时摘要旧记忆、旧历史和当前任务已完成过程；压缩后的请求仍逐字保留
  最新真实用户 `ChatMessage`，且完整请求不超过自动阈值。（对应 AC10；验证：Manager
  和 AgentLoop 测试）
- [x] 固定上下文或最新用户消息导致没有可压缩空间时返回 `context_uncompressible`，
  不调用摘要模型，也不增加失败次数。（对应 AC10；验证：不可压缩测试）
- [x] 摘要请求只包含专用 System Prompt、旧记忆和只读 transcript，不包含主 Agent
  Prompt、环境、权限、工具目录、工具 Schema、Thinking、signature 或 redacted 数据。
  （对应 AC11；验证：摘要请求捕获）
- [x] 摘要请求工具列表为空、Thinking 明确关闭、输出上限为 20,000 Token，Prompt 开头
  和结尾均禁止工具调用。（对应 AC11；验证：Prompt 资源和 Anthropic 参数测试）
- [x] 合法响应依次包含 `<analysis_draft>` 和 `<summary>`；草稿不会进入记忆或历史，
  正式摘要包含九个固定中文标题且顺序正确，空部分为“无”。（对应 AC12；验证：解析测试）
- [x] 标签缺失、标题缺失或乱序、异常停止、Thinking 或工具调用均使本次摘要失败，且
  不会触发第二次修复请求。（对应 AC12；验证：失败表测试）
- [x] “原文”条目通过稳定用户消息 ID 定位，反转 JSON 转义后与来源逐字一致；任何字词
  或标点变化均失败，“概述”不会伪装成原文。（对应 AC13；验证：原话校验测试）
- [x] 第一次压缩后请求中只有一份结构化记忆和一份独立边界提醒；再次压缩会原子替换
  旧记忆，不会堆叠摘要。（对应 AC14；验证：滚动记忆测试）
- [x] 边界提醒位于全部 supplements 最后，明确摘要不是代码事实，要求重新读取文件或
  存盘结果并禁止臆造精确代码。（对应 AC14；验证：完整请求顺序断言）

## 事务、命令与熔断

- [x] 自动摘要后分别模拟正常完成、Provider 失败、用户取消和轮数上限；只有正常完成
  会提交摘要和本轮完整历史。（对应 AC15；验证：AgentLoop/ChatSession 事务测试）
- [x] `/compact` 在低于自动阈值时仍压缩全部已提交历史，不保留最近用户消息，命令本身
  不进入历史；空历史返回 `compact_not_needed` 且不调用模型、不计失败。
  （对应 AC16；验证：ChatSession 命令测试）
- [x] 手动摘要可以通过 Ctrl+C 取消；取消后历史和记忆不变，也不增加连续失败次数。
  （对应 AC16、F22；验证：取消测试）
- [x] 每个主请求预检最多自动摘要一次；失败且原请求不超过继续上限时继续主请求，超过
  上限时停止并提示 `/compact`。（对应 AC17；验证：失败上限测试）
- [x] 自动与手动摘要共用失败计数；连续三次实际失败后自动摘要熔断，手动压缩仍可用；
  任意成功摘要会清零并恢复自动摘要。（对应 AC17；验证：熔断状态测试）

## 终端反馈与兼容性

- [x] 工具结果自动外置不会额外刷屏；摘要成功只显示一次压缩前后 Token，失败显示连续
  次数，第三次明确显示熔断和 `/compact`。（对应 AC18；验证：TerminalUI 测试）
- [x] 未触发外置或摘要时，Anthropic 文本流、工具循环、权限审批、MCP、Plan 模式和
  历史提交行为保持不变。（对应 AC19；验证：现有 Agent、Session 和集成测试）
- [x] OpenAI 分支不创建 ContextManager，不新增上下文配置转换、Provider 请求行为或
  命令适配，现有 PlainChatRunner 测试通过。（对应 AC19；验证：应用装配回归测试）
