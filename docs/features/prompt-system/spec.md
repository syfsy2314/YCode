# YCode 提示词系统 Spec

## 背景

YCode 已具备基础系统指令、工具描述、对话历史、工具循环和任务模式，但稳定规则与
工作区、Shell、工具列表、任务模式等动态内容混合在同一段提示中。这不利于按职责维护
指令，也会让动态变化影响稳定提示词的缓存复用。

本功能建立结构清晰的提示词与消息通道，在保持现有 Agent 行为的同时，为后续动态工具
和外部记忆提供注入边界。

## 目标

- 按职责组织稳定的全局指令，并以确定顺序拼装。
- 分离稳定指令、工具定义、动态系统补充和真实对话历史。
- 让稳定内容可缓存，并能观察缓存创建与命中情况。
- 让环境、模式、工具状态和外部记忆以系统级语义动态进入模型请求。
- 保持现有工具循环、会话事务和安全边界。

## 功能需求

- **F1：内置指令模块**  
  全局指令按身份、行为、工具策略、通用代码规范、安全边界和输出风格等职责拆分。
  模块具有稳定标识和优先级；相同输入必须产生完全一致的顺序和内容。第一阶段只支持
  YCode 内置模块。

- **F2：内容通道与缓存**  
  模型请求明确区分稳定全局指令、工具定义、动态系统补充、真实对话历史和当前用户
  输入。稳定工具定义和全局指令形成可缓存前缀；环境、模式或历史变化不得改变该稳定
  前缀，工具定义变化时允许缓存失效。

- **F3：动态系统补充**  
  环境快照、任务模式、工具状态变化、外部记忆和临时提醒以系统级补充消息进入请求，
  不伪装成用户输入，也不要求模型单独回复。模式与工具状态等持续事件可以进入会话
  历史；环境快照和周期提醒只参与当前请求。

- **F4：环境快照**  
  普通用户回合提供紧凑环境信息，包括工作区路径、操作系统、Shell、本地时间及时区，
  以及可用时的 Git 分支和工作区状态摘要。Git 信息不可用时省略，不得阻止对话。完整
  环境变量、Git diff、完整文件列表和机器标识不进入模型请求。

- **F5：任务模式提醒**  
  会话首次普通用户回合使用完整模式指令，后续用户回合使用精简提醒。模式切换后的
  下一普通用户回合再次使用完整指令，之后恢复精简提醒。模式命令和同一用户任务内的
  Agent 工具轮次不产生额外提醒。

- **F6：工具规则**  
  通用工具策略在全局指令中表达，关键局部规则同时出现在相关工具描述中，包括优先
  使用专用工具和修改前先读取。本阶段不为这些提示性规则新增通用行为状态机，现有
  权限和安全限制继续由运行时强制执行。

- **F7：模型能力兼容**  
  模型支持对话中系统消息时使用原生系统级补充消息；不支持时将动态补充合并到当轮
  顶层系统指令。降级可以牺牲该轮缓存，但不得退化成普通用户消息；同一会话复用已经
  确认的能力结果。

- **F8：记忆与缓存统计边界**  
  系统提供外部记忆的动态注入通道，但不负责生成或管理记忆。系统读取模型响应中的
  输入量、缓存创建量和缓存读取量，转换为供应商无关的统计信息，供测试和诊断使用。

## 非功能需求

- **N1：供应商无关**  
  提示词模块、补充消息、生命周期和使用量统计不依赖供应商 SDK 类型，协议差异由
  Provider 边界处理。

- **N2：安全与上下文控制**  
  提示词、环境快照、诊断和错误不得包含密钥、认证头、完整环境变量或无关机器信息。
  临时补充不得反复写入历史并造成上下文无界增长。

- **N3：失败隔离**  
  环境采集、Git 检查和缓存统计解析失败时，不得破坏正常对话。

- **N4：兼容性**  
  现有结构化历史、Thinking、工具循环、事务式提交、取消、错误处理、轮数限制和
  plan-only 执行边界不得回归。

- **N5：可测试性**  
  模块顺序、请求通道、消息生命周期、模式提醒、能力降级和统计转换可通过本地自动化
  测试验证；真实缓存命中通过人工 API 测试验证。

## 不做的事

- OpenAI 或其他 Provider 的新提示词、系统消息和缓存协议适配。
- 用户级或项目级模板、配置覆盖、自定义模块、插件注册和提示词编辑界面。
- `AGENTS.md` 等项目指令文件的发现与合并。
- 自动记忆提炼、检索、压缩、遗忘或跨会话持久化。
- 对话压缩、摘要、上下文裁剪和完整的 A/B 实验平台。
- 外部工具的发现、安装和连接，以及延迟加载或工具搜索。
- 为提示性工具规则新增通用行为状态机。
- 缓存成本仪表盘、长期统计存储或默认 TUI 用量展示。

## 验收标准

- 稳定全局指令按模块和优先级确定性拼装，动态信息变化不改变稳定缓存前缀。
- 环境、模式、工具状态和外部记忆通过系统级补充消息注入，不伪装成用户输入；临时
  内容不污染历史。
- 会话首次或模式切换后的普通用户回合使用完整模式指令，其余用户回合使用精简提醒，
  Agent 工具轮次不重复追加。
- 支持原生系统补充消息；模型不支持时降级到当轮顶层系统指令。
- 能读取缓存创建与命中统计，并通过一次真实 Anthropic 对话验证缓存生效。
- 现有对话、工具循环、plan-only、安全边界和 OpenAI 纯聊天路径不回归。
- 使用少量典型任务观察工具选择、修改前读取、模式遵守和输出风格。
