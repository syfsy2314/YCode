# YCode 记忆系统 Checklist

> 状态：已验收  
> 每一项都必须通过运行代码或观察行为验证；没有实际证据不得勾选。

## 项目指令与上下文

- [x] **项目根与指令发现**：从包含配置的项目子目录启动时读取项目根 `YCODE.md`；
  文件缺失时正常启动，显式配置使用该配置所在目录。（对应 AC1；验证：项目上下文单元
  测试和应用装配测试）

- [x] **安全模块引用**：第 5 层 `@include` 正常展开；第 6 层、循环、缺失、绝对路径、
  `..` 和符号链接逃逸阻止启动，并指出引用来源。（对应 AC2；验证：项目上下文路径测试）

- [x] **独立指令注入**：Anthropic 请求包含项目指令系统块；普通历史和 JSONL 不包含
  指令正文，压缩和 `/resume` 后仍继续注入。（对应 AC3；验证：请求集成测试）

## 会话存档与恢复

- [x] **统一会话 CRUD**：可以创建、列出、加载和删除会话；每个会话只有一个 JSONL，
  活动会话不能删除，精确删除不影响其他文件。（对应 AC4；验证：SessionManager 单元测试）

- [x] **会话 ID**：首条用户消息生成本地时间加短标题的文件名；中文、空白、非法字符、
  32 字符限制和同秒冲突行为符合 Spec。（对应 AC5；验证：会话 ID 参数化测试）

- [x] **结构化 JSONL**：包含 Thinking 和工具调用的完整回合写出版本、UTC 时间、消息和
  提交边界；没有流式或 TUI 事件，恢复后所有内容块往返一致。（对应 AC6；验证：codec
  与 SessionManager 往返测试）

- [x] **写前提交**：模拟追加或 flush 失败时，内存历史和上下文不变且不会报告成功；
  取消、Provider 错误和轮数超限不产生已提交回合。（对应 AC7；验证：ChatSession 故障
  测试）

- [x] **启动与命令恢复**：默认新建、`--continue` 恢复最新会话、`/resume <id>` 恢复
  指定会话；命令不进入历史，失败时当前会话不变。（对应 AC8；验证：CLI、ChatSession
  和终端交互测试）

- [x] **切换状态隔离**：会话切换后原会话仍可恢复，目标历史生效；Agent 模式、临时
  权限、上下文失败状态和完整模式提醒被重置，MCP 与工具继续可用。（对应 AC9；验证：
  会话切换集成测试）

- [x] **坏行与尾部修复**：坏 JSON 行产生警告并跳过；半回合只恢复到上一提交边界，
  原文件被截断且可以继续追加和再次恢复。（对应 AC10；验证：JSONL 修复测试）

- [x] **工具链修复**：缺少结果、调用 ID 错配或消息顺序错误的工具链不会进入恢复历史，
  文件截断到此前完整回合。（对应 AC11；验证：工具配对状态机测试）

- [x] **恢复压缩检查点**：超限恢复只压缩一次并保存检查点；再次恢复复用检查点；压缩
  失败时原文件和当前活动会话不变。（对应 AC12；验证：上下文检查点集成测试）

- [x] **时间跨度提醒**：超过 24 小时的恢复会话只在第一次后续请求收到本地时间跨度
  提醒；未满阈值或第二次请求不包含。（对应 AC13；验证：固定时钟会话测试）

## 项目记忆

- [x] **目录、分类与格式**：四类文件前缀、`name`、`description`、`type` 和索引内容
  一致；任一项不符时条目无效。（对应 AC14；验证：MemoryStore 参数化测试）

- [x] **只注入索引**：普通请求包含规范化 `MEMORY.md` 索引而不包含主题正文；模型通过
  `read_file` 能读取索引目标。（对应 AC15；验证：Agent 请求与真实读取工具集成测试）

- [x] **记忆失败隔离**：索引缺失不阻止对话；坏索引、缺失主题和无效 front matter
  被跳过并警告；所有路径逃逸均被拒绝。（对应 AC16；验证：MemoryStore 安全测试）

- [x] **退出记忆判断**：存在新增成功回合时，无工具隔离请求收到当前全部有效记忆和
  新增对话；能够返回无变化、创建、更新、合并或删除，程序不执行相似度计算。（对应
  AC17；验证：MemoryUpdater 模拟流测试）

- [x] **跨会话整理**：同一运行中在 A、B 会话产生的新回合都进入退出整理请求，并带有
  会话 ID 和时间边界；恢复前旧历史不重复进入。（对应 AC18；验证：跨会话集成测试）

- [x] **安全应用变更**：合法操作生成完整主题和新索引；删除仅影响当前索引目标。无效
  路径、类别、输出或写入中断时，原有效索引仍可读取且项目外文件不变。（对应 AC19；
  验证：MemoryStore 故障注入测试）

- [x] **正常退出边界**：`/exit`、`/quit` 和空闲 `Ctrl+C` 触发整理；无新增回合不调用
  模型；超过 30 秒或失败时保留记忆、显示非致命提示并正常退出。（对应 AC20；验证：
  TerminalUI 固定超时测试）

## 隐私、兼容与集成

- [x] **本地隐私**：`.ycode/sessions/` 和 `.ycode/memory/` 被 Git 忽略；会话、记忆、
  API Key 和认证头不会出现在错误或警告文本中。（对应 AC21；验证：忽略规则与敏感值
  搜索测试）

- [x] **现有能力不回归**：Anthropic 流式文本、Thinking、工具循环、权限、plan-only、
  MCP、上下文压缩、取消和错误恢复测试通过；OpenAI 纯聊天路径保持原行为且未接入新
  功能。（对应 AC22；验证：完整自动化测试）

- [x] **组件边界成立**：`SessionManager` 是 `.ycode/sessions/` 的唯一读写方，不依赖
  Provider、工具、权限或 TUI；Memory 实现集中在 `ycode/memory/`。（验证：依赖检查、
  单元测试和代码审查）

- [x] **公开文档完整**：README 准确说明 `YCODE.md`、`@include`、JSONL、`--continue`、
  `/resume`、`MEMORY.md`、退出整理及 Anthropic 范围。（验证：文档关键词检查和人工核对）
